环境要求：

如果你使用 Windows，需要先安装 WSL2 (Windows Subsystem for Linux)。这是微软官方的 Linux 兼容层，性能接近原生。

一键安装

关于 uv

Hermes Agent 使用 uv 作为底层安装工具。 uv 是 Astral 团队用 Rust 开发的 Python 包管理器，集 pip + pyenv + virtualenv 于一体，速度比 pip 快 10-100 倍。 安装脚本会自动安装 uv，无需手动操作。

方式一：国内加速安装（推荐）

通过 ghfast.top 代理加速 GitHub 访问，自动安装 uv → Python 3.11 → 克隆仓库 → 安装依赖。

或使用Hermes Agent中文社区镜像源：

方式二：官方命令（可直连 GitHub 时）

方式三：uv tool install（已有 uv 的用户）

uv 会自动创建隔离环境，hermes 命令自动加入 PATH。 国内可加清华镜像：--index-url https://pypi.tuna.tsinghua.edu.cn/simple。 升级用 uv tool upgrade hermes-agent。

开始使用

启动交互式对话

这会打开完整的终端界面 (TUI)，支持多行编辑、斜杠命令自动补全、对话历史和流式工具输出。

常用命令速查

hermes 启动交互式对话
hermes model 选择/切换 LLM 模型
hermes tools 管理启用的工具集
hermes config set 修改配置项
hermes gateway setup 配置消息平台网关
hermes gateway run 启动消息网关（前台）
hermes skills browse 浏览可用技能
hermes update 更新到最新版本
hermes doctor 诊断问题

对话中的斜杠命令

在 CLI 或消息平台中，你可以使用以下斜杠命令控制 Agent：

/new 或 /reset 开始新对话
/model [模型名] 切换模型
/personality [名称] 设置个性
/retry 重新生成上一条回复
/undo 撤销上一轮对话
/compress 压缩上下文（节省 token）
/usage 查看 token 使用情况
/skills 浏览技能列表
/stop 中断当前任务

核心创新

Hermes Agent不是简单地调用LLM，而是通过内置的学习循环不断优化自身：

  • 自动从交互中生成Skill
  • 在使用中连续迭代技能
  • 主动持久化知识和用户偏好
  • 跨会话构建对用户的深度理解

接入社交媒体

接入QQ

在WSL2界面输入命令：

选择QQ Bot按下回车：

选择第一个Scan QR code to add bot automatically，扫码登录，如显示以下：

Open this URL in QQ on your phone:
https://q.qq.com/qqbot/openclaw/connect.html?task_id=xxxxxx
Tip: pip install qrcode to display a scannable QR code here

可直接打开URL，或者通过命令pip install qrcode安装二维码显示工具，安装后重新选择接入QQ

如使用命令pip install qrcode提示找不到 pip，使用：
VIRTUAL_ENV=~/.hermes/hermes-agent/venv uv pip install qrcode

最后执行hermes gateway setup，选择QQ Bot

连接成功后，选择第一项默认Use DM pairing approval

How should direct messages be authorized?
↑↓ navigate ENTER/SPACE select ESC cancel

→ (●) Use DM pairing approval (recommended)
(○) Allow all direct messages
(○) Only allow listed user OpenIDs

后续全部回车默认即可，等待重启网关后，通过QQ机器人进行对话。

高级配置

路径：

~/.hermes/config.yaml

示例：

platforms:
qq:
enabled: true
extra:
markdown_support: true
dm_policy: “open”
group_policy: “open”

接入微信

在WSL2界面输入命令：hermes gateway setup，选择Weixin / WeChat，选择扫码登录

首次连接会提示：

Here’s your pairing code: 599XXXXX

Ask the bot owner to run:

hermes pairing approve weixin 599XXXXX

在WSL2界面输入：hermes pairing approve weixin 599XXXXX即可连接成功。
